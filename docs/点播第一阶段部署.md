# 点播第一阶段部署

## 1. 文档范围

这份文档记录第一阶段已经确认可行的落地步骤，从 Docker 安装开始，到基础服务启动、MinIO 初始化、MySQL 建表、服务端目录准备为止。

第一阶段目标不是做上传，而是先跑通下面这条链路：

1. 服务端导入视频
2. 服务端转码 HLS
3. API 返回播放地址
4. 现有 Qt 播放器播放 `m3u8`

当前默认环境：

- Ubuntu 虚拟机网络可用
- 虚拟机 IP：`192.168.99.128`
- 网络模式：`NAT`
- 第一阶段所有基础服务都部署在这台虚拟机

---

## 2. 第一阶段需要部署什么

第一阶段统一部署在虚拟机上：

- `MySQL`
- `Redis`
- `MinIO`
- 后续再加：
  - `API 服务`
  - `Worker`
  - `Nginx`

建议第一阶段统一用 `Docker Compose` 管理，不要分别手工安装 `MySQL / Redis / MinIO`。

原因：

- 更省事
- 迁移方便
- 出问题更容易排查
- 后续 `API` 和 `Worker` 可以直接用 Docker 网络访问这些服务

---

## 3. 安装 Docker

### 3.1 添加 Docker 官方源

在 Ubuntu 中执行：

```bash
sudo apt update
sudo apt install -y ca-certificates curl

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo ${UBUNTU_CODENAME:-$VERSION_CODENAME}) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

### 3.2 启动 Docker

```bash
sudo systemctl enable docker
sudo systemctl start docker
sudo usermod -aG docker $USER
newgrp docker
```

### 3.3 验证 Docker

```bash
docker --version
docker compose version
docker ps
```

参考输出：

```text
Docker version 29.3.0, build 5927d80
Docker Compose version v5.1.1
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
```

## 5. 编写 docker-compose.yml

在 `~/vod-platform` 下创建 `docker-compose.yml`：

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: vod-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: root123456
      MYSQL_DATABASE: vod_platform
      MYSQL_USER: vod_user
      MYSQL_PASSWORD: vod_pass_123
      TZ: Asia/Shanghai
    volumes:
      - ./data/mysql:/var/lib/mysql

  redis:
    image: redis:7
    container_name: vod-redis
    restart: unless-stopped
    ports:
      - "6380:6379"

  minio:
    image: minio/minio:latest
    container_name: vod-minio
    restart: unless-stopped
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
      TZ: Asia/Shanghai
    command: server /data --console-address ":9001"
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - ./data/minio:/data
```

### 5.1 关于端口的说明

#### MySQL

这里没有映射宿主机端口。

原因：

- 虚拟机里已经存在一个本机 MySQL 的可能性较大
- 第一阶段 `API` 和 `Worker` 后面会通过 Docker 网络访问 `mysql:3306`
- 当前不强制要求宿主机直接连容器里的 MySQL

如果后面确实需要从宿主机连接容器里的 MySQL，可以改成：（2026-03-24，已经改成  3307）

```yaml
    ports:
      - "3307:3306"
```

#### Redis

这里使用：

```yaml
ports:
  - "6380:6379"
```

原因：

- 宿主机原先 `6379` 已被占用
- 改成 `6380` 后可以避免端口冲突

#### MinIO

当前对外开放：

- `9000`：MinIO API
- `9001`：MinIO 控制台

## 9. 创建第一阶段最小表结构

在 MySQL 中执行：

```sql
USE vod_platform;

CREATE TABLE IF NOT EXISTS videos (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT NULL,
    source_object_key VARCHAR(512) NOT NULL,
    cover_object_key VARCHAR(512) NULL,
    play_object_key VARCHAR(512) NULL,
    status VARCHAR(32) NOT NULL DEFAULT 'uploaded',
    duration_ms BIGINT NULL,
    width INT NULL,
    height INT NULL,
    file_size BIGINT NULL,
    mime_type VARCHAR(128) NULL,
    transcode_error TEXT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    published_at TIMESTAMP NULL DEFAULT NULL
);

CREATE TABLE IF NOT EXISTS transcode_jobs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    video_id BIGINT NOT NULL,
    job_type VARCHAR(32) NOT NULL DEFAULT 'hls',
    status VARCHAR(32) NOT NULL DEFAULT 'pending',
    retry_count INT NOT NULL DEFAULT 0,
    payload_json JSON NULL,
    started_at TIMESTAMP NULL DEFAULT NULL,
    finished_at TIMESTAMP NULL DEFAULT NULL,
    error_message TEXT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_transcode_jobs_video_id FOREIGN KEY (video_id) REFERENCES videos(id)
);
```

## 12. 安装 Go 并初始化服务端模块

### 12.1 安装 Go

```bash
sudo apt update
sudo apt install -y golang-go
go version
```

### 12.2 初始化 Go 项目

```bash
cd ~/vod-platform/server
go mod init vod-platform-server
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
go get github.com/go-sql-driver/mysql
go get github.com/minio/minio-go/v7
go get github.com/minio/minio-go/v7/pkg/credentials
```

到这一步为止，服务端代码目录已经可以开始写导入脚本。

### 12.3 如果 `go get` 连不上 `proxy.golang.org`

如果出现类似错误：

```text
Get "https://proxy.golang.org/...": connect: connection refused
```

说明当前网络环境下默认 Go 代理不可达。

先执行：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
```

然后重试：

```bash
go get github.com/go-sql-driver/mysql
go get github.com/minio/minio-go/v7
go get github.com/minio/minio-go/v7/pkg/credentials
```

如果仍然卡在校验阶段，可以临时关闭校验：

```bash
go env -w GOSUMDB=off
```

再执行一次 `go get`。

查看当前 Go 代理配置：

```bash
go env GOPROXY
go env GOSUMDB
```

## 13. 下一步要做什么

基础环境完成后，下一步按下面顺序继续：

1. 写导入脚本
   把本地视频导入 MinIO 的 `raw-media`
2. 导入脚本写库
   在 `videos` 表插入记录
3. 导入脚本建任务
   在 `transcode_jobs` 表插入 `pending`
4. 写 Worker
   读取任务并转码 HLS
5. 写 API
   返回视频列表和视频详情
6. 客户端对接
   让 Qt 播放器拿 `playUrl` 播放

- `MySQL`
- `Redis`


如果后面仅容器内部访问 Redis，也可以取消宿主机映射。
